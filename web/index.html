새 도메인 추가

허용 문자: a-z 0-9 - _ .

    도메인 편집

    * 없으면 정확 매칭(apex만 — coupang.com은 apex만 매칭), *.coupang.com은 서브도메인(멀티 라벨 포함) 매칭. 여러 도메인이 겹치면 가장 긴 패턴이 우선합니다. 최대 32개, 각 253바이트 이하, 문자 a-z 0-9 - . *만.
    예시(자유 입력): product, category, search, landing, article, policy, unknown — 새 값도 가능

      페이지 타입 설정

      URL 패턴으로 페이지 타입(product/category/…)을 판정하는 hot-path 설정입니다. 우선순위가 높은 규칙부터 평가됩니다.

      Spin이 허용하는 값 중에서만 선택 (product/category/search/landing/article/policy/unknown).

      hot_path_rules

      각 행: 페이지 타입 + URL 패턴(콤마 구분, * 와일드카드) + 우선순위. 저장 시 콤마 입력은 배열로 분해됩니다.
